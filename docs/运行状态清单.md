## 四、已知 Bug（Phase 0 修复对象）

1. 时区：9 处 `toISOString().slice(0,10)`，中国 UTC+8 早上 8 点前"今天"算成昨天。
2. HTML 转义：`escHtml` 仅用于面试练习历史，其余渲染函数插值用户数据未转义。
3. `Store.set` 无 try/catch，配额满抛未捕获异常。
4. 演示数据回填：清空后刷新会重新注入。
5. `ivView` 表格视图被强制重置为卡片。
6. 缺口：无数据导出/导入。
